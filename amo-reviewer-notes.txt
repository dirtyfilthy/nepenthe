Nepenthe deletes browsing data for sites the user hasn't visited within a time limit they choose. It only reads and deletes: no network requests, no remote code, no eval or innerHTML, and it stores only its settings and the counts from the last run. It starts switched off and previews the first run before the user confirms.

The code is plain, unbundled JavaScript. All deletion is in src/sweep.js, which takes the browser API as a parameter ("api") so it can be unit tested.

Why each permission is needed:

- history: find sites visited within the limit (history.search) and delete older visits (history.deleteRange).
- cookies + <all_urls>: list cookies in every cookie store, including partitioned ones (cookies.getAll), and remove those of expired sites (cookies.remove). Firefox needs host permission for a cookie's domain to read or remove it, and an expired site can be any site. There are no content scripts, and no web requests are read or changed. If the user withdraws host permission, the settings page says so and offers to grant it again.
- contextualIdentities (new in 0.1.6): list every container's cookie store (contextualIdentities.query, in cookieStoreIds in src/sweep.js). cookies.getAllCookieStores only reports stores with a tab open, so expired cookies in a container with no open tab were never found. Read only: no container is created, changed or removed.
- browsingData: delete localStorage, IndexedDB and service workers of expired sites by hostname (browsingData.remove), clear the HTTP cache (browsingData.removeCache; per-host clearing removes nothing under network partitioning), and delete form history since a time for the two "forget" buttons (browsingData.removeFormData).
- downloads: remove download-list entries older than the limit (downloads.search, downloads.erase). Downloaded files are never touched.
- sessions: forget recently closed tabs and windows older than the limit (sessions.getRecentlyClosed, forgetClosedTab, forgetClosedWindow).
- tabs: read open tabs' URLs (tabs.query) so open sites count as active and keep their cookies.
- alarms: run the check every 15 minutes and shortly after startup.
- storage: save settings and the last run's counts (storage.local).

Generated file: src/psl-data.js is the Public Suffix List (https://publicsuffix.org/, MPL-2.0) converted by tools/build-psl.mjs into one string assignment, globalThis.PSL_RULES = "...", with no other code. It groups hostnames into sites (src/domain.js). To rebuild: download https://publicsuffix.org/list/public_suffix_list.dat and run node tools/build-psl.mjs public_suffix_list.dat. The list changes upstream, so a fresh build differs only by rules added or removed since.

The uploaded source is a git archive of the release commit. There is no build step: the files in the add-on are the files in the repository. Tests: npm test (unit) and npm run e2e (real Firefox).
